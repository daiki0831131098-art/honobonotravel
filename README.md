# tabi note

旅を計画し、旅のしおりにまとめ、写真から旅ムービーを作るためのWebアプリです。

## コンセプト

旅行前の計画、旅行中に見るしおり、旅行後に残すムービーを一つの旅プランにつなげます。
「予定を詰める」だけでなく、旅の気分や余白も一緒に記録できる体験を目指します。

## 現在の機能

### 旅を計画する

- 旅程をタイムライン形式で表示
- 旅行情報と旅のムードを表示
- 複数の旅行プランをサイドバーから切替
- 新しい旅行プランをアプリ内モーダルから作成
- 場所を検索して地図付きスポットとして追加
- 作成したプランをブラウザの `localStorage` に保存

### 旅のしおり

- 旅の表紙プレビュー
- 旅の概要とメッセージ
- 持ちものチェックリスト
- 予定一覧
- 印刷・PDF出力の導線

### 旅ムービー

- 写真一覧のプレビュー
- 写真の選択・選択解除
- cinematic / sunny days / documentary のスタイル切替
- 音楽の選択UI
- 再生・一時停止のプレビュー操作

## 起動方法

依存関係やビルド手順はありません。

1. [index.html](index.html) をブラウザで開く
2. サイドバーから「旅を計画する」「旅のしおり」「旅ムービー」を切り替える
3. `MY TRIPS` の `＋` から新しい旅行プランを作成する

外部のGoogle FontsとUnsplash画像を利用しているため、初回表示時はインターネット接続があると見た目が安定します。

## 技術方針

現在は静的なブラウザアプリとして、素早く体験を検証できる構成にしています。
今後、データ量やユーザー数が増えた段階で、フロントエンドとAPI、永続データベースを分離します。

- 既存のHTML/CSS/JavaScriptを活かして段階的に拡張する
- 旅行プラン、行程、しおり、写真、ムービーを同じプランIDで関連づける
- ブラウザ内で完結する機能と、サーバーが必要な機能を分ける
- 写真や動画など容量の大きいデータはデータベースに直接保存しない

## 現在の制約

- 旅行プランの保存先はブラウザごとの `localStorage`
- 複数端末間の同期やログインは未対応
- 「編集する」「フォルダを変更」は現在UI導線のみ
- 写真フォルダの読み込みは未実装
- 動画ファイルの生成・ダウンロードは未実装
- PDF出力は未実装
- 外部画像が取得できない環境では画像が表示されない場合がある

## 開発の進め方

大きな機能を一度に作り込まず、まずは旅行プランのデータ構造を安定させます。
その後、計画データをしおりとムービーへ受け渡し、最後に認証・同期・動画生成などのサーバー機能を追加します。

詳細は [ROADMAP.md](ROADMAP.md) を参照してください。
